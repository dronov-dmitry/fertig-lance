# 🌐 Обзор биржи

👉 **[Открыть Fertig-Lance](https://dronov-dmitry.github.io/fertig-lance/)**

В этой папке находится статический веб-интерфейс платформы **Fertig‑Lance**. Пользовательский интерфейс включает следующие ключевые возможности:

* **Просмотр площадки** — навигация по списку лотов с ценами, описаниями и данными о продавцах.
* **Поиск и фильтрация** — быстрый поиск активов по названию, категории или диапазону цен.
* **Детализация лота** — отдельная страница с полными характеристиками товара и контактами продавца.
* **Действия пользователя** — регистрация, вход в систему и управление собственными объявлениями (создание, редактирование, удаление).
* **Адаптивный дизайн** — интерфейс оптимизирован для работы в браузерах на ПК и мобильных устройствах.
